## 1️⃣ Icono personalizado
Aqui lo que hacemos es crear o subir nuestras propias imagenes para ser utilizadas en nuestra apk e incluso en el sistema web, esto nos permite darle mejor estetica y diseño al apk.
En Ionic, los íconos se generan a partir de una imagen base mediante el comando:
npx capacitor-assets generate
